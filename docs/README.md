- [History and reasoning](../dev-docs/georeferencing-history.md) : les décisions prises et pourquoi.

- [Roadmap](../dev-docs/georeferencing-roadmap.md) : les améliorations possibles, classées.
- [Dev test tool](../dev-docs/dev-test-tool.md) : l'outil interne de création et d'évaluation des cas de test.
